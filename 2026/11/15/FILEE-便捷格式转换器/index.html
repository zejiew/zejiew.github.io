FILEE-便捷格式转换器

zejiew2026-11-152026-11-15

一款通过引导用户跳过安装复杂工具，如ffmpeg等带格式转化的命令行工具，最终使用ui 一键集合和调用。非常便捷。

地址:https://github.com/KnifeLemon/Filee

用拖放操作的免费开源文件格式转换器。
按住一个键（Ctrl，macOS 为 Option）拖动文件，光标处会弹出格式圆环，放到想要的格式上即可。

官网 · 下载 · LinkedIn · 安装 · 命令行 · 开发

English · Español · 日本語 · 한국어 · 简体中文 · 繁體中文 · Polski · हिन्दी · Русский · العربية · فارسی · Português (Brasil) · Português (Portugal) · Français · ไทย · Türkçe · Bahasa Indonesia · Italiano · বাংলা

就在光标旁
无需打开应用窗口。 只显示适合当前拖动文件的格式，就在你所在的位置。 		270 种格式，无需其他软件
图片、PDF、Word、Excel、PowerPoint、HWP、电子书、压缩包、字体、CAD、3D 模型和地理信息数据，无需 Office、韩文办公软件或 LibreOffice。 		只在你的电脑上
不上传任何文件。 Filee 离线工作，结果保存在原文件旁边。

实际效果


27 秒视频和可交互演示请访问 filee.sh

安装

从 Releases 下载。

或使用 WinGet：

  • Windows 10/11 运行 Filee-<version>-win-Setup.exe，或解压 win-Portable.zip 后运行 Filee.exe。
    • 安装程序是 Filee 自己的，使用与 Filee 相同的语言，电脑上无需另外安装任何组件。
    • 安装时可以添加资源管理器菜单、登录时启动、filee 命令和可选引擎。
    • 静默安装沿用 Inno Setup 的参数（/VERYSILENT /SUPPRESSMSGBOXES）。
  • macOS 13 及以上（预览）解压 osx-arm64 或 osx-x64 包并运行 ./install.sh。
    • 也可以打开 .dmg，把 Filee 拖到“应用程序”文件夹（filee 命令只由 install.sh 添加）。
    • 目前尚未公证，首次启动时请在系统设置 → 隐私与安全性中点 仍要打开。
  • Linux x64、ARM64（Ubuntu 22.04 及以上）解压后运行 ./install.sh（无需 root，需要 Python 3）。
    • 拖动手势需要 X11，Wayland 下请使用拖放区域和文件管理器的右键菜单。

有新版本时 Filee 会在菜单中提示，更新时保留设置和引擎。
更新后会用几张幻灯片介绍新功能。

Windows：Filee 无法启动（没有窗口也没有报错）？
这种情况发生在长期未更新的 Windows 10 上，且电脑的处理器支持“硬件强制堆栈保护”（CET）。
Windows 会开启这项保护，却缺少 .NET 需要的一项功能，于是 Filee 和安装程序会立即退出。

  • 推荐：安装 Windows 更新中可用的更新（最新的累积更新）。
  • 无法更新时：通常只对 Filee 关闭这项保护就能启动。
    以管理员身份打开 PowerShell 并运行：

安装程序也运行同样的命令，换成它的文件名（例如 Filee-<version>-win-Setup.exe）；使用便携版 ZIP 则只需上面两行。
要撤销，请在“Windows 安全中心 → 应用和浏览器控制 → Exploit Protection 设置 → 程序设置”中删除这些条目。

功能

  • 光标旁的圆环，按住按键拖动文件，放到格式上即可。
    只显示适合这些文件的格式。
  • 直接从浏览器拖，Chrome、Edge、Firefox 或 Safari 里的图片、文件链接和下载项也能这样拖放。
    • Filee 会保存到“下载”文件夹（也可以只保留转换后的文件）再转换。
    • 链接下载时不使用浏览器的登录信息。
  • 每种文件类型一个工具栏，拖放排列。
    下列项目都能用预设设置：
    • 质量、尺寸、DPI
    • PDF 页面和压缩
    • 视频音频
    • 保存位置和文件名
  • 圆环有背面，圆环打开时按 Tab 或转动鼠标滚轮翻过来，背面是不常用的格式和工具。
  • 转换前先裁剪，“裁剪”会逐张打开图片。
    拖动选框、选择比例，只保存选中的部分。
  • 一次转换多个文件，并行处理。
    需要多步的转换（HWP → HWPX → DOCX）会自动找到路线。
  • 监视文件夹，放入的文件自动转换。
  • 最近的转换显示在主页上，每项都有缩略图，可以直接“打开文件”，也可以用“打开方式”换个应用打开。
  • 其他方式 右键菜单、键盘快捷键、拖放区域和 filee 命令。
  • 浅色和深色主题，可自选强调色和环形工具栏不透明度，支持 English、Español、日本語、한국어、简体中文、繁體中文、Polski、हिन्दी、Русский、العربية（从右到左）、Português (Brasil)、Français、नेपाली、ไทย、Türkçe、Português (Portugal)、Deutsch、Italiano、Bahasa Indonesia、Tiếng Việt。

命令行

filee 命令使用与应用相同的引擎和预设（安装程序或 install.sh 会添加它）。

全部命令和选项见 filee.sh/zh-cn/cli 或 filee help。

开发

在 Windows、macOS 或 Linux 上使用 .NET 10 SDK 构建。

代码签名政策

Filee 由 Myeonggu Kim（KnifeLemon）开发和发布。

  • Windows 版本使用颁发给 Myeonggu Kim 的 Certum 开源代码签名证书签名。
    • 2.0.0 及更早的版本没有签名。

详细政策和隐私政策见英文 README。
Filee 不会上传文件，也不会发送任何使用数据。
